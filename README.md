# FundCaster

**FundCaster** is a decentralized crowdfunding mini-app built for the Farcaster ecosystem. It allows users to raise funds for projects, grants, or personal causes directly from a Farcaster Frame on Base.

## Features
- **Smart Contract**: Built with Foundry, deployed on Base Sepolia.
- **Micro-Funding**: Accept ETH donations with a minimum threshold ($5 USD).
- **Farcaster Native**: 1-click funding via Frames.

## Tech Stack
- **Contracts**: Solidity, Foundry
- **Frontend**: Next.js, RainbowKit, Wagmi
- **Frame**: OnchainKit

## Usage

### Build
```shell
make build
```

### Test
```shell
make test
```

### Deploy
```shell
make deploy-sepolia
```
